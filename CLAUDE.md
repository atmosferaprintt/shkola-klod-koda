# Школа клод-кода

Мини-платформа обучения Claude Code: 30 дней по часу, отметки прогресса ученика.

## Правила проекта
- Всё содержание курса только в `js/course.js`, разметка и логика его не дублируют.
- Стиль: brutalist mono, плашки, крупная нумерация, палитра paper/ink/acid из `css/style.css`.
- В текстах никаких длинных тире, никакого канцелярита, объяснения простыми словами для новичка.
- Прогресс хранится в localStorage под ключом `shkola-klod-koda-v2`. При изменении структуры данных менять версию ключа.
- Никаких внешних библиотек: чистые HTML, CSS, JS.
- Палитра «Уголь»: тёмный графит `#151517`, карточки `#1e1e21`, акцент янтарь `#e3a008`, текст на акценте `#1a1408`. Все цвета только через токены в `:root` файла `css/tracker.css`.
- Интерфейс: трекер месяца (календарь из 30 клеток) плюс разделы Навыки, GPT, Ресурсы, Словарь, Отчёт. Другие концепции интерфейса были удалены после выбора заказчика.

## Структура
- `index.html` — каркас, вкладки, шторка дня
- `css/tracker.css` — оформление
- `js/course.js` — данные: weeks, days, gptkit, glossary, resources
- `js/store.js` — хранение прогресса и подсчёты
- `js/tracker.js` — рендер разделов
- `ПЛАН.md` — программа обучения текстом
